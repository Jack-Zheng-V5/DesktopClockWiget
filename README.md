# 桌面时钟小组件 (Desktop Clock Widget)

这是一个使用C#开发的Windows桌面时钟小组件，具有悬浮功能、自定义大小、闹钟和开机自启动等特性。

## 下载与安装

从 [Releases 页面](https://github.com/Jack-Zheng-V5/DesktopClockWiget/releases) 下载最新的 `DesktopClockWidget_1.0.1.0_x64.msix` 和 `DesktopClockWidget.cer` 两个文件。

安装包为 x64 自包含发布，**无需安装 .NET 运行时**，要求 Windows 10 1809（内部版本 17763）及以上。

### 安装步骤

1. **先安装证书**（仅首次需要）：双击 `DesktopClockWidget.cer` → 点击"安装证书" → 选择"本地计算机" → 勾选"将所有的证书都放入下列存储" → 浏览选择"受信任人" → 完成。
   也可以用管理员 PowerShell 执行：
   ```powershell
   Import-Certificate -FilePath .\DesktopClockWidget.cer -CertStoreLocation Cert:\LocalMachine\TrustedPeople
   ```
2. **安装应用**：双击 `DesktopClockWidget_1.0.1.0_x64.msix`，按提示安装即可。

> 由于安装包使用自签名证书，Windows 可能提示"无法验证发布者"，按上述步骤先安装证书即可正常安装。

## 功能特性

1. **传统圆形钟表盘**：直观的模拟时钟界面，显示时、分、秒针
2. **悬浮功能**：支持通过鼠标拖动修改时钟的位置
3. **设置界面**：可以自定义时钟的各种属性
4. **调整大小**：通过设置界面调整时钟的大小
5. **闹钟功能**：支持设置多个闹钟，到时会显示在所有窗口最上层并发出震动效果
6. **开机自启动**：可以设置应用程序随Windows系统一起启动

## 使用方法

### 基本操作
- **拖动时钟**：使用鼠标左键按住并拖动时钟到任意位置
- **打开设置**：右键点击时钟，选择"设置"选项
- **退出程序**：右键点击时钟，选择"退出"选项

### 设置闹钟
1. 在设置界面中，选择"闹钟设置"部分
2. 设置小时和分钟
3. 点击"添加闹钟"按钮
4. 可以启用或禁用已添加的闹钟，也可以删除不需要的闹钟

### 修改时钟大小
1. 在设置界面中，拖动"时钟大小"滑块
2. 点击"保存"按钮应用更改

### 设置开机自启动
1. 在设置界面中，勾选"开机自动启动"复选框

## 开发环境

- 编程语言：C#
- 框架：.NET 6.0 Windows Forms
- 开发工具：Visual Studio

## 编译和运行

1. 使用Visual Studio打开`DesktopClockWidget.sln`解决方案文件
2. 还原NuGet包
3. 构建解决方案（F6）
4. 运行应用程序（F5）

## 注意事项

- 应用程序的设置和闹钟数据保存在用户的应用数据目录下
- 闹钟触发时，会显示一个置顶窗口并使时钟窗口震动
- 如果需要彻底卸载，请先取消开机自启动设置
